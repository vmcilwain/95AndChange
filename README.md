# 95&Change LLC — Website

Static marketing site for 95&Change LLC, served via GitHub Pages.

## Structure

```
index.html      Landing page
privacy.html    Privacy Policy
terms.html      Terms of Service
assets/
  styles.css    Site styles (Maryland flag palette)
  favicon.svg   Site icon
```

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

GitHub Pages serves the `main` branch from the repository root. Enable it under
**Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`**.
